# SkyStore

Учебный Django‑проект магазина. В репозитории реализованы главная страница и форма обратной связи.

## Запуск проекта

1. Установите Python 3.13.
2. Создайте и активируйте виртуальное окружение.
3. Установите зависимости через `poetry install` или `pip install -r requirements.txt`.
4. Выполните миграции `python manage.py migrate`.
5. Запустите сервер командой `python manage.py runserver`.

## Правила работы с репозиторием

- Используйте Poetry для управления зависимостями.
- Не размещайте секретные данные в `config/settings.py`.
- Шаблоны хранятся в `catalog/templates`, статические файлы — в каталоге `static`.
- Соблюдайте стиль PEP8 при написании кода.
- Для добавления приложений используйте `python manage.py startapp <app_name>`.
- Предложения и исправления отправляйте через Pull Request.
